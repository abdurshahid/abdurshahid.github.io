# Abdur Rahman Bin Shahid — Academic Website

Personal academic website built with the al-folio Jekyll theme.

## Deployment

The only GitHub Actions workflow is `.github/workflows/deploy.yml`.
It builds the site and publishes the generated files to the `gh-pages` branch.
GitHub Pages should be configured to serve `gh-pages` from `/ (root)`.

## Main content

- `_pages/about.md` — biography and research overview
- `_projects/` — research programs and featured projects
- `_bibliography/papers.bib` — selected publications
- `_pages/people.md` — students and research team
- `_pages/teaching.md` — teaching
- `_pages/service.md` — professional service
- `assets/pdf/Shahid_CV.pdf` — academic CV
