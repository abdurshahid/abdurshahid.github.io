# Customization notes

This starter site has been populated from the supplied academic CV.

Before publishing:
1. Replace `assets/img/prof_pic.svg` with a professional photo named `prof_pic.jpg`, then update `_pages/about.md`.
2. Confirm the Google Scholar ID in `_data/socials.yml`.
3. Add LinkedIn, GitHub, ORCID, and other profiles to `_data/socials.yml`.
4. Review `_bibliography/papers.bib` and add DOI, URL, PDF, code, and award metadata.
5. Update `url` and `baseurl` in `_config.yml` for the final GitHub Pages repository.
6. Add project images to `assets/img/` and reference them in each `_projects/*.md` file if desired.
7. Replace broad student descriptions with approved bios, headshots, and links if students consent.
